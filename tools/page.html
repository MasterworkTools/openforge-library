OpenForge guide gaps

For each guide in openforge-catalog: which textures can be built from start to finish, and which answers lead to a part that does not exist. The guide engine itself judged every reachable combination of answers against the fixtures.

Each card under a guide is one missing piece. Each row on a card is the shortest set of answers that runs into it; any answer not named there can be anything. Dual-clip bases are left out: they are plain-only by design.

The ids are beads issues under openforge-8lx in openforge-library.
